# Student Profile

## Overview

The Student Profile is a web-based project developed using HTML. It provides a structured and organized layout to display student information, educational qualifications, hobbies, daily schedule, and contact details through a simple webpage.

## Features

* Student Information Display
* Profile Image Section
* Educational Qualifications Table
* Hobbies List
* Daily Schedule List
* Contact Form
* Clean and Organized Layout

## Technologies Used

* HTML5
